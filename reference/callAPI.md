# Call API

Call API

## Usage

``` r
callAPI(action, ...)
```

## Arguments

- action:

  (character) name of the endpoint, one of "mapping-ids", "dbsources",
  "iso-data" or "mapping"

- ...:

  parameters for the endpoint, e.g. mappingId = "IsoMemo", dbsource =
  "LiVES, field = "site,longitude", ...
